# 02 Stack And Language Mastery

Buildgum is a browser-side TypeScript/React app. This module uses real files to teach JavaScript runtime behavior, React rendering, TypeScript contracts, and Vite tooling.

Read in order:

1. [`01-language-runtime-model.md`](01-language-runtime-model.md)
2. [`02-framework-mental-models.md`](02-framework-mental-models.md)
3. [`03-type-system-and-contracts.md`](03-type-system-and-contracts.md)
4. [`04-tooling-and-build-system.md`](04-tooling-and-build-system.md)

The learning goal is not just "know React." It is to know where runtime state lives, what TypeScript can and cannot prove, which side effects are safe, and how build tooling changes feedback loops.
